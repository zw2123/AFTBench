\subsection{Key Findings}

\textbf{Null result:} All ablation variants show identical performance to I5-full (mean difference = 0.00, all ties).

\textbf{Interpretation:}
\begin{itemize}
    \item The deterministic scripted agent does not differentially utilize AFT primitives
    \item Primitive benefits may be agent-dependent (require LLM or adaptive agent)
    \item Alternatively, primitives may provide overhead costs without reliability gains for simple tasks
    \item This null result is scientifically valid and informative
\end{itemize}

\textbf{Limitations:}
\begin{itemize}
    \item Scripted agent follows fixed policy, cannot exploit advanced features
    \item Task set may not exercise primitive-specific failure modes
    \item Larger task set or LLM agent may reveal primitive contributions
\end{itemize}

\subsection{Discussion}

The null ablation result suggests that AFT primitives do not improve reliability for the deterministic scripted agent on the current task set. This finding is consistent with the hypothesis that:

\begin{enumerate}
    \item Primitive benefits are agent-dependent (require adaptive decision-making)
    \item Primitive benefits are task-dependent (require specific failure modes)
    \item Primitive overhead may offset reliability gains for simple tasks
\end{enumerate}

Future work with LLM agents and expanded task sets may reveal primitive-specific benefits.
