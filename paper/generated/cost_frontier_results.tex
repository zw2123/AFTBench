\subsection{Pareto Frontier}

A condition is Pareto-efficient if no other condition dominates it on both reliability and cost.

\textbf{Pareto-optimal set:} $\{$I0, I2, I5$\}$

\begin{itemize}
    \item \textbf{I0:} Highest reliability (100\%) but highest cost (246 tokens)
    \item \textbf{I2:} Best cost/reliability ratio (100\% correct, 20 tokens)
    \item \textbf{I5:} Only condition with recovery (29.6\%), moderate reliability (67\%)
\end{itemize}

\textbf{Dominated conditions:} I1, I3, I4 (same cost as I2, lower reliability)

\subsection{Key Findings}

\begin{enumerate}
    \item \textbf{Selective discovery is the strongest primitive.} I2 achieves 100\% correctness with 92\% fewer context tokens than I0/I1.
    
    \item \textbf{Recovery is I5's unique contribution.} I5 is the only interface with non-zero recovery success (29.6\%).
    
    \item \textbf{Full AFT does not dominate simpler interfaces.} I5-full (66.7\% correct) is outperformed by I2 (100\%) and several ablation variants (75--80\%).
    
    \item \textbf{No safety violations observed.} Zero duplicate, unintended, or unauthorized effects across all 1,392 runs. The scripted agent is well-behaved.
    
    \item \textbf{Timing overhead is not meaningfully measurable.} All wall-clock times are sub-millisecond for synthetic tasks.
\end{enumerate}

\subsection{Recommendations}

\begin{itemize}
    \item \textbf{Simple, low-risk tasks:} Use I2 (selective discovery) for best cost/reliability ratio
    \item \textbf{Post-commit uncertainty:} Use I5 for recovery capability
    \item \textbf{High-reliability requirements:} Use I0 if cost is not a concern
    \item \textbf{Avoid I1, I3, I4:} Dominated by I2 on both cost and reliability
\end{itemize}
