\section{Experimental Setup}

\subsection{Interface Conditions}
We evaluate six interface conditions representing progressive adoption of Agent-First Tooling primitives:

\begin{itemize}
    \item \textbf{I0 (Legacy):} Synchronous request-response, no lifecycle management
    \item \textbf{I1 (Schema-Normalized):} Input validation, structured envelopes
    \item \textbf{I2 (Discovery-Aware):} Selective discovery, compact metadata
    \item \textbf{I3 (Lifecycle-Aware):} Invocation identity, resumable execution
    \item \textbf{I4 (Effect-Aware):} Effect contracts, preconditions, idempotency
    \item \textbf{I5 (Full AFT):} Durable state, reconciliation, verification
\end{itemize}

\subsection{Ablation Conditions}
To isolate the contribution of each AFT primitive, we define seven ablation variants of I5:

\begin{itemize}
    \item \textbf{I5-minus-selective-discovery:} Full catalog exposure
    \item \textbf{I5-minus-resumable-invocation:} No resume capability
    \item \textbf{I5-minus-observable-execution:} No status queries
    \item \textbf{I5-minus-structured-output:} Free-form results
    \item \textbf{I5-minus-side-effect-contract:} No preconditions/postconditions
    \item \textbf{I5-minus-durable-state:} Process-local state only
    \item \textbf{I5-minus-verification:} No postcondition checking
\end{itemize}

\subsection{Benchmark Worlds}
Four controlled synthetic worlds provide diverse operational scenarios:

\begin{itemize}
    \item \textbf{Enterprise Records:} CRM-like contact/account management (8 tasks)
    \item \textbf{Long-Running Jobs:} Multi-stage background jobs (8 tasks)
    \item \textbf{Large Catalog:} Tool discovery at scale 10--1000 (8 tasks)
    \item \textbf{External Actions:} Message/event operations (8 tasks)
\end{itemize}
